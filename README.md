# my-agent-skills

My personal library of agent skills and reusable tooling.

## Contents

| Folder | What it is |
|---|---|
| [`ppt-style-kit/`](ppt-style-kit/) | **"Deep Indigo" PPT style kit** — a reusable presentation style extracted from my final-year project deck (`ppt final.pptx`). Encodes the palette, Montserrat typography, corner-dot motif and 10 slide-layout components as a `pptxgenjs` module. Ships a `.potx` for working in PowerPoint. |

### ppt-style-kit at a glance

```bash
cd ppt-style-kit
cp fonts/*.ttf ~/.local/share/fonts/ && fc-cache -f   # one-time
node example.js                                       # builds the reference deck
```

Edit `example.js` — swap the content, keep the `K.*` calls — and run it to get a
new deck in the same style. Full spec in [`ppt-style-kit/README.md`](ppt-style-kit/README.md).

Plots are **not** generated by the kit. Produce PNG/JPEG images yourself and drop
them in with `K.figure(...)`, which preserves their aspect ratio.
